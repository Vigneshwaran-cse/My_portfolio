# K. Vigneshwaran — Developer Portfolio

A lightweight, responsive, static portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Run locally

No package installation or build step is required.

1. Clone the repository.
2. Open the folder in VS Code.
3. Start it with the Live Server extension, or run:

   \`python -m http.server 5500\`

4. Visit \`http://localhost:5500\`.

## Project structure

- \`index.html\` — page structure, profile content and project descriptions
- \`style.css\` — dark visual system, responsive layouts and motion
- \`script.js\` — mobile navigation, active section state, reveal effects, project filters and copy-email action
- \`img/profile photo.jpg\` — portfolio portrait

## Content maintenance

Before publishing profile updates, verify education, CGPA, internship dates, achievements, contact information and project status. Project descriptions intentionally distinguish completed work from work in progress and concepts.

The contact section uses a direct email link. It does not pretend to submit a form through a backend service.

## Deployment

The site can be hosted on GitHub Pages, Netlify, Vercel or any static hosting provider. Publish the repository root; no framework build command is required.

## Accessibility and performance notes

- Semantic landmarks and a skip link
- Keyboard-visible focus states
- Accessible mobile navigation and project filter state
- Reduced-motion support
- No client-side framework or 3D rendering dependency
